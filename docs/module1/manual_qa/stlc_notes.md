# STLC (Software Testing Life Cycle)

**STLC** — это процесс тестирования, который является частью SDLC.

## 6 этапов STLC:
1. **Анализ требований (Requirement Analysis):** Изучаем ТЗ, ищем неоднозначности.
2. **Планирование тестирования (Test Planning):** Выбираем инструменты (pytest, Playwright), оцениваем сроки.
3. **Разработка тест-кейсов (Test Case Development):** Пишем тест-кейсы, готовим тестовые данные.
4. **Настройка тестовой среды (Test Environment Setup):** Разворачиваем стенд, БД.
5. **Выполнение тестов (Test Execution):** Прогоняем тесты, заводим баг-репорты.
6. **Завершение цикла (Test Cycle Closure):** Подводим итоги, пишем отчет.

## Важные термины:
- **Entry Criteria** — условия для старта этапа (например, "ТЗ утверждено").
- **Exit Criteria** — условия завершения (например, "90% тестов пройдено успешно").
- **RTM (Requirements Traceability Matrix)** — таблица, связывающая требования и тест-кейсы.
